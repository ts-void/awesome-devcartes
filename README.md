## Desktop (Wayland)

### [sway](https://github.com/swaywm/sway)
- **Language:** C
- **Why awesome:** Tiling compositor that replaces i3 on Wayland and is configured entirely through a plain text file.
- **Project:** https://github.com/swaywm/sway

### [fuzzel](https://codeberg.org/dnkl/fuzzel)
- **Language:** C
- **Why awesome:** Fast, lightweight Wayland launcher that is easy to wire into your own scripts.
- **Project:** https://codeberg.org/dnkl/fuzzel

### [clipman](https://github.com/chmouel/clipman)
- **Language:** Go
- **Why awesome:** Clipboard manager for Wayland that keeps your history and plays well with wl-clipboard and launchers like fuzzel.
- **Project:** https://github.com/chmouel/clipman

## Terminal & Shell

### [foot](https://codeberg.org/dnkl/foot)
- **Language:** C
- **Why awesome:** Minimalist Wayland terminal emulator that starts instantly and uses very few resources.
- **Project:** https://codeberg.org/dnkl/foot

## CLI Tools

### [bat](https://github.com/sharkdp/bat)
- **Language:** Rust
- **Why awesome:** cat with syntax highlighting and Git integration, without losing pipe compatibility.
- **Project:** https://github.com/sharkdp/bat

### [eza](https://github.com/eza-community/eza)
- **Language:** Rust
- **Why awesome:** Modern ls with colors, icons and Git status that works as a drop-in replacement.
- **Project:** https://github.com/eza-community/eza

### [btop](https://github.com/aristocratos/btop)
- **Language:** C++
- **Why awesome:** A beautiful, interactive resource monitor that shows CPU, memory, disks, network and running processes in a single terminal dashboard.
- **Project:** https://github.com/aristocratos/btop

## Editors & Development

### [helix](https://github.com/helix-editor/helix)
- **Language:** Rust
- **Why awesome:** Modal editor with built-in LSP and Tree-sitter that is productive out of the box, no plugins needed.
- **Project:** https://github.com/helix-editor/helix

## File Management

### [yazi](https://github.com/sxyazi/yazi)
- **Language:** Rust
- **Why awesome:** Blazing-fast terminal file manager with async previews for images and documents.
- **Project:** https://github.com/sxyazi/yazi
