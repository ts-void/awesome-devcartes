## Desktop (Wayland)

### [sway](https://github.com/swaywm/sway)
- **Language:** C
- **Why awesome:** Tiling compositor that replaces i3 on Wayland and is configured entirely through a plain text file.
- **Project:** https://github.com/swaywm/sway

### [fuzzel](https://codeberg.org/dnkl/fuzzel)
- **Language:** C
- **Why awesome:** Fast, lightweight Wayland launcher that is easy to wire into your own scripts.
- **Project:** https://codeberg.org/dnkl/fuzzel

### [clipman](https://github.com/chmouel/clipman)
- **Language:** Go
- **Why awesome:** Clipboard manager for Wayland that keeps your history and plays well with wl-clipboard and launchers like fuzzel.
- **Project:** https://github.com/chmouel/clipman

## Terminal & Shell

### [foot](https://codeberg.org/dnkl/foot)
- **Language:** C
- **Why awesome:** Minimalist Wayland terminal emulator that starts instantly and uses very few resources.
- **Project:** https://codeberg.org/dnkl/foot

### [zsh](https://www.zsh.org/)
- **Language:** C
- **Why awesome:** Powerful interactive shell with advanced customization, programmable completion and scripting capabilities.
- **Project:** https://www.zsh.org/

### [zsh-autosuggestions](https://github.com/zsh-users/zsh-autosuggestions)
- **Language:** Zsh
- **Why awesome:** Suggests commands from your history as you type, making repetitive terminal work much faster.
- **Project:** https://github.com/zsh-users/zsh-autosuggestions

### [zsh-completions](https://github.com/zsh-users/zsh-completions)
- **Language:** Zsh
- **Why awesome:** Adds hundreds of additional completion definitions for commands and tools, making tab completion much more powerful.
- **Project:** https://github.com/zsh-users/zsh-completions

### [zsh-syntax-highlighting](https://github.com/zsh-users/zsh-syntax-highlighting)
- **Language:** Zsh
- **Why awesome:** Highlights commands as you type, helping you spot invalid commands and syntax errors before execution.
- **Project:** https://github.com/zsh-users/zsh-syntax-highlighting

## CLI Tools

### [aria2](https://github.com/aria2/aria2)
- **Language:** C++
- **Why awesome:** Lightweight multi-protocol download utility supporting HTTP, HTTPS, FTP, BitTorrent and Metalink with parallel downloads.
- **Project:** https://github.com/aria2/aria2

### [bat](https://github.com/sharkdp/bat)
- **Language:** Rust
- **Why awesome:** cat with syntax highlighting and Git integration, without losing pipe compatibility.
- **Project:** https://github.com/sharkdp/bat

### [eza](https://github.com/eza-community/eza)
- **Language:** Rust
- **Why awesome:** Modern ls with colors, icons and Git status that works as a drop-in replacement.
- **Project:** https://github.com/eza-community/eza

### [btop](https://github.com/aristocratos/btop)
- **Language:** C++
- **Why awesome:** A beautiful, interactive resource monitor that shows CPU, memory, disks, network and running processes in a single terminal dashboard.
- **Project:** https://github.com/aristocratos/btop

## Editors & Development

### [helix](https://github.com/helix-editor/helix)
- **Language:** Rust
- **Why awesome:** Modal editor with built-in LSP and Tree-sitter that is productive out of the box, no plugins needed.
- **Project:** https://github.com/helix-editor/helix

### [zola](https://github.com/getzola/zola)
- **Language:** Rust
- **Why awesome:** Fast static site generator written in Rust that builds complete websites without requiring a database or JavaScript runtime.
- **Project:** https://github.com/getzola/zola

## File Management

### [yazi](https://github.com/sxyazi/yazi)
- **Language:** Rust
- **Why awesome:** Blazing-fast terminal file manager with async previews for images and documents.
- **Project:** https://github.com/sxyazi/yazi

## Android & Devices

### [scrcpy](https://github.com/Genymobile/scrcpy)
- **Language:** C, Java
- **Why awesome:** Mirrors and controls Android devices over USB or Wi-Fi with remarkably low latency, without requiring root or installing an app.
- **Project:** https://github.com/Genymobile/scrcpy

## Multimedia

### [vlc](https://www.videolan.org/vlc/)
- **Language:** C, C++
- **Why awesome:** Versatile media player that plays almost any audio and video format without requiring additional codecs.
- **Project:** https://www.videolan.org/vlc/

## Hardware & Peripherals

### [openrgb](https://openrgb.org/)
- **Language:** C++
- **Why awesome:** Controls RGB lighting across devices from different manufacturers through one unified application, without vendor-specific software.
- **Project:** https://openrgb.org/

### [solaar](https://github.com/pwr-Solaar/Solaar)
- **Language:** Python
- **Why awesome:** Linux device manager for Logitech wireless peripherals that exposes battery status, device settings and advanced features.
- **Project:** https://github.com/pwr-Solaar/Solaar
