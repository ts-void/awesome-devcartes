# Awesome Devcartes

A curated, lean list of my Linux tools, with one sentence on why each one is awesome.

## Desktop (Wayland)

- [sway](https://github.com/swaywm/sway) - Tiling compositor that replaces i3 on Wayland and is configured entirely through a plain text file.
- [fuzzel](https://codeberg.org/dnkl/fuzzel) - Fast, lightweight Wayland launcher that is easy to wire into your own scripts.

## Terminal & Shell

- [foot](https://codeberg.org/dnkl/foot) - Minimalist Wayland terminal emulator that starts instantly and uses very few resources.

## CLI Tools

- [bat](https://github.com/sharkdp/bat) - cat with syntax highlighting and Git integration, without losing pipe compatibility.
- [eza](https://github.com/eza-community/eza) - Modern ls with colors, icons and Git status that works as a drop-in replacement.

## Editors & Development

- [helix](https://github.com/helix-editor/helix) - Modal editor with built-in LSP and Tree-sitter that is productive out of the box, no plugins needed.

## File Management

- [yazi](https://github.com/sxyazi/yazi) - Blazing-fast terminal file manager with async previews for images and documents.
- [clipman](https://github.com/chmouel/clipman) - Clipboard manager for Wayland that keeps your history and plays well with wl-clipboard and launchers like fuzzel.
